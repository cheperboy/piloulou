# Arduino
Affiche la valeur d'un capteur d'humidité et déclenche une alarme si seuil bas atteint.  
Appui sur l'un des deux bouton: arrêt l'alarme, puis attend indéfiniment.  
Appui sur les deux boutons permet d'accéder au menu de réglage de la valeur seuil.  

# parts
* arduino Uno
* LCD snootlab deuligne
* screwshield
